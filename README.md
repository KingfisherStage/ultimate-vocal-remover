# Ultimate Vocal Remover

### AI-powered vocal and instrument separation

Ultimate Vocal Remover (UVR) uses state-of-the-art deep learning models to separate vocals from instrumentals, isolate drums, bass, and other stems — making it the go-to tool for remixing, karaoke, and audio production.

<br>

---

## Features

| | |
|:---|:---|
| **Multiple AI Models** | Demucs, MDX-Net, VR Architecture — choose the best for your audio |
| **Full Stem Separation** | Isolate vocals, drums, bass, piano, guitar individually |
| **Batch Processing** | Process entire albums or music libraries automatically |
| **High Fidelity** | Artifact-free separation that preserves the original audio quality |
